Code Evidence:

utils/otp.js

createOTP(), verifyOTP()

OTP expiration (5 minutes)

OTP marked as “used” after verification

After password verification, the system enforces a second authentication factor using a time-bound OTP, thereby preventing unauthorized access even if credentials are compromised.
